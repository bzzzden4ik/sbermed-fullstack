# База знаний SIRIUS (RAG)

Каждый файл `*.md` — один документ: `# Заголовок` — название, каждый раздел `## ...` — отдельный фрагмент поиска.
Файлы, имя которых начинается с `_`, не индексируются.

Содержимое — демонстрационное, сгенерировано для хакатона. Перед реальным использованием проверьте цены, правила и контакты.

Индексация: `python ../../deploy/ingest_knowledge.py` из `backend/hackathon-hospital` (на сервере выполняется автоматически в `deploy/update.sh`).
Повторно отправляются в OpenAI только новые и изменённые разделы.
